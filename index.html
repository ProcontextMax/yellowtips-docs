API Documentation

Context APIs for AI agents in LATAM & Spain. This guide covers authentication, endpoints, and error handling.

Quick start

Make your first request in 30 seconds.

cURL
curl https://api.yellowtips.com/health

You should see:

{"status":"success","data":{"service":"yellowtips-api","version":"0.3.0"}}

Authentication

All endpoints under /v1/* require an API key in the X-API-Key header.

X-API-Key: yt_live_abc123...
Don't have a key? Request one at yellowtips.com — the Free plan includes 100 calls/month without a credit card.

POST /v1/legal/verify-citation

Verifies a legal citation in three layers: existence, relevance and temporality (dead law detection).

POST /v1/legal/verify-citation

Headers

Header Required Value
X-API-Key Yes Your API key (starts with yt_live_)
Content-Type Yes application/json

Request body

Field Type Required Description
citation string Yes The citation to verify (e.g. "Sentencia C-567 de 2019")
jurisdiction string Yes One of: MX, CO, AR, CL, PE, ES
proposition string No The legal proposition the citation is supposed to support
Example request
curl -X POST https://api.yellowtips.com/v1/legal/verify-citation \
  -H "Content-Type: application/json" \
  -H "X-API-Key: yt_live_abc123..." \
  -d '{
    "citation": "Sentencia C-1234 de 2014",
    "jurisdiction": "CO",
    "proposition": "derecho de retracto"
  }'
Success response — dead law detected
{
  "status": "success",
  "data": {
    "citation": "Sentencia C-1234 de 2014",
    "jurisdiction": "CO",
    "citation_id": "C-1234-2014",
    "citation_text": "Sentencia C-1234 de 2014",
    "court": "Corte Constitucional",
    "year": 2014,
    "existence_check": "confirmed",
    "relevance_check": "unverified",
    "temporality_check": "dead_law",
    "superseded_by": "C-567-2019",
    "overall_confidence": "low",
    "note": "Derogada por Sentencia C-567 de 2019",
    "plan": "free",
    "timestamp": "2026-10-23T18:34:37.858Z"
  }
}
Success response — valid citation
{
  "status": "success",
  "data": {
    "citation": "Sentencia C-567 de 2019",
    "citation_id": "C-567-2019",
    "existence_check": "confirmed",
    "relevance_check": "likely_relevant",
    "temporality_check": "valid",
    "overall_confidence": "high",
    "note": "Vigente. Reemplaza a C-1234 de 2014"
  }
}
Partial response — citation not in database
{
  "status": "partial",
  "data": {
    "citation": "Sentencia X-9999 de 2020",
    "existence_check": "not_found",
    "temporality_check": "unknown",
    "overall_confidence": "low",
    "error": {
      "code": "E_CITATION_NOT_FOUND",
      "message": "Citation not found in our database..."
    }
  }
}
Note: a not_found result does not mean the citation doesn't exist — it means our coverage is limited. We never fabricate a "valid" response when we can't verify.

GET /v1/legal/argument

Extract structured legal reasoning. This endpoint returns the core problema_juridico, the ratio_decidendi, and the exact decision_texto (what was ordered). It supports automatic query expansion to match Spanish accents.

GET /v1/legal/argument

Headers

Header Required Value
X-API-Key Yes Your API key (starts with yt_live_)

Query parameters

Param Type Required Description
q string Yes Search query. Words of 6+ letters are automatically expanded (e.g., "pension" matches "pensiones" and "pensión").
sentido string No Filter by decision outcome: concede, niega, modula, mixto, or indeterminado.
derecho string No Filter by affected right (e.g., pension, estabilidad, discapacidad, salud).
limit integer No Max results (1–20, default 10)
Example request
curl "https://api.yellowtips.com/v1/legal/argument?q=pension&sentido=concede&limit=2" \
  -H "X-API-Key: yt_live_abc123..."
Success response
{
  "status": "success",
  "data": {
    "query": "pension",
    "fts_query": "pensi*",
    "filters": {
      "sentido": "concede",
      "derecho": null
    },
    "limit": 2,
    "count": 1,
    "plan": "pro",
    "results": [
      {
        "id": "T-334-24",
        "sentido": "concede",
        "derechos": "[\"discapacidad\",\"pension\",\"salud\"]",
        "problema_juridico": "en resolver si: Colpensiones vulneró los derechos...",
        "ratio_decidendi": "",
        "decision_texto": "Primero. REVOCAR la Sentencia proferida el 17 de enero...",
        "snippet_problema": "...la pensión de sobrevivientes...",
        "titulo": "Sentencia T-334/24 – Tutela",
        "fecha": "2024-08-12",
        "ponente": "Diana Constanza Fajardo Rivera",
        "fuente_url": "https://www.corteconstitucional.gov.co/relatoria/2024/T-334-24.htm"

    ]
  }
}

GET /v1/legal/argument/hybrid

Hybrid search that combines BM25 lexical matching (SQLite FTS5) with vector semantic search (Cloudflare Vectorize + @cf/baai/bge-m3), fused via Reciprocal Rank Fusion (RRF, k=60). Best endpoint for natural-language queries like "me despidieron por estar enfermo".

Exact citations such as T-229/25 are auto-detected and resolved via direct primary-key lookup, bypassing the AI/Vectorize stack for sub-10ms latency.

GET /v1/legal/argument/hybrid

Headers

Header Required Value
X-API-Key Yes Your API key (starts with yt_live_)

Query parameters

Param Type Required Description
q string Yes Search query. Citation patterns (T-229/25, C-001-23, SU-500/24) trigger a direct lookup. Otherwise, runs hybrid BM25 + vector search.
sentido string No Filter by decision outcome: concede, niega, modula, mixto, or indeterminado.
derecho string No Filter by affected right (e.g., pension, estabilidad, discapacidad, salud).
limit integer No Max results (1-20, default 10)
Example request (natural-language query)
curl "https://api.yellowtips.com/v1/legal/argument/hybrid?q=me%20despidieron%20por%20estar%20enfermo&limit=3" \
  -H "X-API-Key: yt_live_abc123..."
Success response
{
  "status": "success",
  "data": {
    "query": "me despidieron por estar enfermo",
    "fts_query": "me OR despidier* OR estar OR enfer*",
    "filters": { "sentido": null, "derecho": null },
    "limit": 3,
    "fusion": "rrf",
    "rrf_k": 60,
    "branches": {
      "lexical":  { "count": 30, "failed": false },
      "semantic": { "count": 30, "failed": false, "error": null }
    },
    "degraded": false,
    "count": 3,
    "plan": "pro",
    "results": [
      {
        "id": "T-225-26",
        "score": 0.0328,
        "branches": ["lexical", "semantic"],

        "titulo": "Sentencia T-225/26 - Tutela",
        "fecha": "2026-04-15",
        "semantic_score": 0.523,
        "snippet_problema": "...me despidieron por enfermo..."
      }
    ]
  }
}
Example request (citation lookup)

GET /v1/legal/search

Full-text search across our jurisprudence database with BM25 relevance ranking, powered by SQLite FTS5. Results include a snippet with matching terms wrapped in <mark> tags — ready to render.

GET /v1/legal/search

Headers

Header Required Value
X-API-Key Yes Your API key (starts with yt_live_)

Query parameters

Param Type Required Description
q string Yes Search query. Multi-word queries are matched as exact phrases. Special characters are sanitized.
tipo string No Filter by ruling type: T (tutela), C (constitutionality), SU (unification)
limit integer No Max results (1–20, default 10)
Example request
curl "https://api.yellowtips.com/v1/legal/search?q=despido%20sin%20justa%20causa&limit=3" \
  -H "X-API-Key: yt_live_abc123..."
Success response
{
  "status": "success",
  "data": {
    "query": "despido sin justa causa",
    "fts_query": "\"despido sin justa causa\"",
    "tipo": null,
    "limit": 3,
    "count": 3,
    "plan": "pro",
    "results": [
      {
        "id": "T-123-26",
        "titulo": "Sentencia T-123/26 – Tutela",
        "fecha": "2026-05-07",
        "ponente": "Lina Marcela Escobar Martínez",
        "tipo": "T",
        "tipo_proceso": "Tutela",
        "fuente_url": "https://www.corteconstitucional.gov.co/relatoria/2026/T-123-26.htm",
        "snippet": "...despido sin justa causa...",
        "rank": -4.115677207344352
      }
    ],
    "timestamp": "2026-10-24T15:44:26.100Z"
  }
}

Rendering snippets

The snippet field contains <mark> tags around matching terms. Render it as HTML to highlight results:

<p dangerouslySetInnerHTML={{ __html: result.snippet }} />
// → "...despido sin justa causa..."

Relevance ranking

Results are ordered by rank (BM25 score). More negative = more relevant. Use it only to sort results within a single query — do not compare rank values across queries.

Coverage: currently 1.428 tutelas (type T) from 2023–2026 are fully searchable. C and SU rulings are in progress.

Jurisdictions

Yellow Tips is Colombia-first. The current corpus covers rulings from the Colombian Constitutional Court (Corte Constitucional) only.

Country Status Coverage
CO — Colombia Available 1.428 tutelas (2023–2026) · 305 verifiable citations
MX — Mexico Roadmap —
AR — Argentina Roadmap —
CL — Chile Roadmap —
PE — Peru Roadmap —
ES — Spain Roadmap —
Why Colombia first? Colombia has one of the most accessible open-data portals in LATAM (datos.gov.co) and a high volume of constitutional rulings. We prioritize depth over breadth: a dense, verifiable corpus for one jurisdiction beats a shallow one for six. Other countries will be added once the Colombian corpus reaches 10,000+ rulings.
